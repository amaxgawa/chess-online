# ♞ Chess Lounge · 체스 라운지

친구들과 함께 두는 **3D 온라인 1:1 체스**예요. 회원가입 없이 닉네임만 입력하면 로비로 들어가고, 방을 만들거나 목록에서 골라 바로 대국할 수 있어요.
별도 서버 없이 **GitHub Pages 같은 정적 호스팅**에 올려서 쓰는 걸 전제로 만들었어요.

## 주요 기능

- **로비**: 실시간 방 목록(대기중·게임중), 방 만들기, 빠른 입장, 접속자 목록, 로비 채팅, 친구 초대, 비밀방
- **대기실**: 두 자리와 관전석, 준비/시작, 시간 제한·진영(백/흑/랜덤/교대) 설정, 강퇴, 방장 위임, 채팅
- **3D 체스판**: 원목·대리석·토너먼트·미드나잇 보드, 각도를 자유롭게 돌려 볼 수 있음(기본 약 45°)
  - 애니메이션: 포물선 이동, 나이트 점프, 잡힌 말이 옆 트레이로 날아감, 캐슬링, 프로모션 변신, 체크메이트 시 킹이 쓰러짐, 시작할 때 말이 떨어지는 연출
  - 클릭 이동과 드래그 이동, 이동 가능한 칸 표시, 모바일 터치 지원
- **정통 규칙**(chess.js): 캐슬링, 앙파상, 프로모션(언더프로모션 포함), 체크메이트, 스테일메이트, 3회 동형반복, 50수 규칙, 기물 부족, 시간패(상대가 메이트할 기물이 없으면 무승부)
- **대국 기능**: 체스 시계(증가 시간 포함), 무르기 요청, 무승부 제안, 기권, 기보(SAN) 탐색, PGN 복사, 이모지 반응, 관전
- **안정성**: 새로고침하거나 잠깐 끊겨도 진행 중이던 게임에 자동으로 다시 연결돼요. 상대가 나가면 45초 뒤 승리 처리를 할 수 있어요.
- **전적**: 레이팅(Elo), 승·무·패, 연승, 백/흑 별 성적, 레이팅 그래프, 최근 대국 다시보기, 상대별 전적
  - 고유 ID 기준으로 저장해서 **닉네임을 바꿔도 전적이 유지**돼요. 백업 코드로 다른 기기에 옮길 수 있어요.
- **라이트/다크 테마**, 효과음(파일 없이 직접 합성), 연습 모드(혼자 또는 한 기기에서 둘이)
- **체스말 세트**: 이미지를 넣어 나만의 말 세트를 만들 수 있고, 고른 세트는 상대 화면에도 똑같이 보여요. → [assets/pieces/README.md](assets/pieces/README.md)

## 실행해 보기 (로컬)

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭하면 동작하지 않아요. 아무 정적 서버로 폴더를 열어 주세요.

```bash
# Node.js가 있다면
npx serve .
# 또는 Python이 있다면
python -m http.server 8080
```

브라우저 창을 두 개 띄우되(하나는 시크릿 창), 서로 다른 닉네임으로 들어가면 혼자서도 대국을 테스트할 수 있어요.

## GitHub Pages에 배포하기

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올려요.
   ```bash
   git init
   git add .
   git commit -m "Chess Lounge"
   git branch -M main
   git remote add origin https://github.com/<아이디>/<저장소>.git
   git push -u origin main
   ```
2. 저장소의 **Settings › Pages**에서 **Source를 `Deploy from a branch`**로, **Branch를 `main` / `(root)`**로 정하고 저장해요.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 주소로 접속하면 끝이에요. 이 주소를 친구들에게 보내 주세요.

빌드 과정이 없고, 필요한 라이브러리는 `vendor/`에 모두 들어 있어요.

## 동작 방식

- 서버 대신 **무료 공개 MQTT 브로커**(WebSocket)로 실시간 통신을 해요(기본 EMQX, 안 되면 HiveMQ, Mosquitto 순서로 시도).
  - 접속자 정보는 브로커에 남아 있는 메시지(retained)와 연결이 끊기면 자동으로 지워지는 기능(Last Will)으로 관리해요.
  - 방 목록은 각 방장의 접속 정보에서 만들어지고, 방장 화면이 그 방의 상태를 책임져요.
  - 수를 둘 때마다 전체 기보를 함께 보내서, 메시지가 하나 빠져도 스스로 맞춰져요.
- 전적, 프로필, 설정은 각자 브라우저의 **localStorage**에 저장돼요.

## 설정 (`js/config.js`)

| 항목 | 설명 |
|---|---|
| `NAMESPACE` | 로비 이름공간이에요. 이 프로젝트를 복사해서 따로 쓰려면 끝의 무작위 문자열을 바꾸세요. 같은 값을 쓰는 사이트끼리는 로비를 공유해요. |
| `BROKERS` | 시도할 공개 브로커 목록이에요(순서가 중요해요. 모두 같은 브로커에 있어야 서로 보여요). |
| `CUSTOM_BROKER` | 개인 브로커(HiveMQ Cloud나 EMQX Serverless 무료 플랜 등)를 쓸 때 주소와 계정을 넣어요. |

- **우리끼리 로비**: 주소 뒤에 `?lobby=이름`을 붙이면 그 링크로 들어온 사람끼리만 보이는 별도 로비가 열려요. (설정 › 서버에서 링크를 복사할 수 있어요.)

## 알아 두면 좋은 점

- 공개 브로커는 누구나 쓰는 테스트용 서버라 가끔 느려지거나 끊길 수 있어요. 앱이 자동으로 다시 연결하지만, 오래 쓸 생각이라면 `CUSTOM_BROKER`로 무료 개인 브로커를 연결하는 걸 추천해요.
- 공개 브로커에서는 채팅이나 수 같은 메시지를 이론상 제3자도 볼 수 있어요. 민감한 대화는 하지 마세요.
- 친구끼리 쓰는 걸 전제로 해서, 전적과 레이팅은 각자 기기에 저장되고 서버 검증은 없어요.
- 다른 탭에서 같은 브라우저로 접속하면 이전 탭의 연결이 끊겨요(같은 사람이 중복 접속하지 않도록).

## 폴더 구조

```
index.html          화면 뼈대, 아이콘, import map
css/style.css       디자인(라이트/다크 테마, 반응형)
js/main.js          앱 시작, 화면 전환, 전역 동작
js/net.js           MQTT 통신, 접속자 표시
js/lobby.js         로비(방 목록, 접속자, 채팅, 초대)
js/room.js          대기실(방장/참가자/관전자, 준비·시작, 방장 위임)
js/game.js          대국(규칙, 시계, 동기화, 무르기/무승부/기권, 결과·전적)
js/stats.js         전적 화면(레이팅 그래프, 최근 대국, 상대 전적)
js/settings.js      설정, 프로필, 체스말 세트 선택
js/pieceSets.js     체스말 이미지 세트 불러오기
js/store.js         localStorage 저장(프로필·전적·설정·백업)
js/sound.js         효과음 합성(Web Audio)
js/three/           3D 보드·말·텍스처·애니메이션(three.js)
assets/pieces/      체스말 이미지 세트(sets.json)
vendor/             three.js 0.186 · chess.js 1.4 · mqtt.js 5.16
```
