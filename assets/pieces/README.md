# 체스말 이미지 세트 추가하기

이 폴더에 이미지를 넣고 `sets.json`에 등록하면, 게임 안 **체스말 세트** 목록(로비 › 내 체스말 › 바꾸기)에서 고를 수 있어요.
각자 고른 세트가 **자기 진영의 말**이 되고, **상대와 관전자 화면에도 똑같이** 보여요.

이미지 말은 이렇게 표시돼요.

- 카메라를 어디로 돌려도 항상 **정면**을 보는 2D 그림
- 진영 색 받침대(백 = 아이보리, 흑 = 흑단)
- 오른쪽 위 **역할 배지**(킹·퀸·룩·비숍·나이트·폰)와 역할별 크기 차이(킹이 가장 크고 폰이 가장 작아요)
- 둘이 같은 세트를 고르면 흑 쪽 그림은 어둡게

## 1. 이미지 준비

- **배경이 투명한 PNG**를 권장해요. 크기는 64~256px 정도면 충분해요.
- 도트(픽셀) 그림은 작게 넣어도 선명하게 확대돼요(아래 `"pixel": true`).
- 그림의 아래쪽(발)이 이미지 아래 끝에 닿게 잘라 두면 받침대 위에 자연스럽게 서요.

## 2. 폴더 만들기

```
assets/pieces/
├─ sets.json
└─ my-set/
   ├─ king.png
   ├─ queen.png
   ├─ rook.png
   ├─ bishop.png
   ├─ knight.png
   └─ pawn.png
```

이미지를 **1장만** 넣어도 돼요. 그러면 모든 말이 같은 그림이고, 크기와 역할 배지로 구분돼요.
역할별 이미지를 일부만 넣으면 빠진 역할은 첫 번째 이미지로 채워져요.

## 3. `sets.json`에 등록

```json
{
  "sets": [
    {
      "id": "my-set",
      "name": "내 세트",
      "folder": "my-set",
      "images": {
        "king": "king.png",
        "queen": "queen.png",
        "rook": "rook.png",
        "bishop": "bishop.png",
        "knight": "knight.png",
        "pawn": "pawn.png"
      },
      "pixel": true
    },
    {
      "id": "one-pic",
      "name": "한 장 세트",
      "folder": "one-pic",
      "images": "character.png"
    }
  ]
}
```

| 항목 | 설명 |
|---|---|
| `id` | 영문 소문자·숫자·`-`로 된 고유 이름이에요. 상대에게는 이 값만 전달돼요. |
| `name` | 화면에 보이는 이름이에요. |
| `folder` | 이미지 폴더예요(`assets/pieces` 기준). |
| `images` | 역할별 파일(`king`/`queen`/`rook`/`bishop`/`knight`/`pawn`, 또는 `k`/`q`/`r`/`b`/`n`/`p`), 또는 파일 이름 하나예요. |
| `pixel` | `true`면 도트 그림을 선명하게 확대해요. 생략하면 작은 이미지(160px 이하)는 자동으로 적용돼요. |
| `scale` | 크기 배율이에요. 기본값은 `1`이고 `0.4`~`2` 사이로 정할 수 있어요. |
| `badge` | 역할 배지 표시 여부예요. 기본값은 `true`예요. |
| `flip` | `true`면 흑 진영 그림을 좌우로 뒤집어요(서로 마주 보게). |
| `desc` | 선택 화면에 보이는 짧은 설명이에요. |

## 4. 올리기

GitHub에 커밋하고 푸시한 뒤 1~2분 지나서 새로고침하면 목록에 나타나요.

- 웹 서버는 **파일 이름의 대소문자를 구분**해요. `King.png`와 `king.png`는 다른 파일이에요.
- 친구 화면에도 보이려면 이미지가 이 사이트에 올라가 있어야 해요. 친구가 예전 버전을 보고 있다면 새로고침해 달라고 해 주세요.
- 세트를 지우거나 `id`를 바꾸면, 그 세트를 고른 사람의 말은 자동으로 클래식 3D 말로 보여요.
- 다른 사람이 만든 그림을 쓸 때는 저작권에 유의하세요. 이 저장소가 공개되어 있으면 이미지도 함께 공개돼요.
